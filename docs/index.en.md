# grok_build_switch

`grok_build_switch` is a local tray tool for Windows that manages Grok Build's `config.toml`. Save different upstreams, API keys, default models, web-search models and explore/plan subagent models as provider profiles, then switch between them with one click.

## Quick links

- [Usage guide](usage.md)
- [Project repository](https://github.com/1parado/grok-build-switch)
- [Contact](contact.md)

## What it's good for

- Managing multiple Grok Build upstream configurations
- Quickly switching between providers, models and API keys
- Automatically backing up `config.toml` before each switch
- Configuring and editing through a local Web panel
- Opening the panel or switching providers from the Windows tray menu
- Automatic new-version notifications, with download or skip right in the update banner
